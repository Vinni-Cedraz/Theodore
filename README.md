# Theodore 🎋

A thoughtful AI companion that helps craft meaningful birthday messages and cards. Transform cherished memories into beautifully written birthday greetings.

## About

Theodore helps users express their deepest feelings through personalized birthday cards. By sharing meaningful memories about their loved ones, users receive beautifully crafted messages that capture the essence of their relationships.

## Features

- **Memory-Based Messages**: Share a cherished memory and receive a beautifully crafted birthday message
- **AI-Generated Content**: Uses OpenAI to generate both personalized text and matching imagery

## Technical Stack

- Built with Flutter/Dart
- Material Design 3 UI
- OpenAI Integration (coming soon)
- Cross-platform support
